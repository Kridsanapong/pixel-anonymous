# 🎮 PixelChat - Anonymous Pixel Art Chat

แอพแชทแบบไม่ระบุตัวตน ดีไซน์ Pixel Art

## ✨ คุณสมบัติ

- 🔒 **Anonymous**: ไม่ต้องการลงทะเบียนหรือระบุตัวตน
- 🗑️ **Auto-delete**: ลบแชทอัตโนมัติเมื่อคนสุดท้ายออก หรือครบ 24 ชม.
- 💾 **Keep messages**: เก็บแชทได้สูงสุด 72 ชม.
- 📸 **Media support**: ส่งรูป วิดีโอ ได้
- 📞 **Voice/Video call**: โทรผ่าน WebRTC
- 🎨 **Pixel Art**: ดีไซน์สไตล์เกม retro
